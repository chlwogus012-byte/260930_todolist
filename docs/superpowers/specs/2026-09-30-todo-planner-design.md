# 할일·일정 통합 관리 웹 앱 — 설계 스펙

날짜: 2026-09-30

## 1. 목적과 성공 기준

- 노션·캘린더 같은 기존 도구를 대체하는 가벼운 할일·일정 도구.
- 해결할 불편: (1) 우선순위·오늘 할 일 정리가 안 됨, (2) 할일과 일정이 따로 놂, (3) 너무 복잡함.
- 사용자: 본인 + 지인 몇 명. 각자 계정, 데이터는 사용자별로 분리. 공유·협업 없음.
- 성공 기준: 기존 도구를 열지 않고 이 앱만으로 "오늘 뭐부터 하지?"가 한 화면에서 해결된다.

## 2. 구조

- 프론트엔드: 웹 SPA (PWA: 폰 홈 화면에 추가 가능). PC·폰 반응형.
- 백엔드: BaaS (제안: Supabase. 확정 전에 공식 문서로 검증 — 구현 계획 단계의 첫 작업). 직접 만드는 서버 없음.
- 인증: 이메일 로그인. 사용자별 데이터 분리는 행 단위 접근 규칙(RLS 등)으로 강제.
- 외부 캘린더 연동 없음. 일정은 앱 안에서 직접 입력.

## 3. 데이터 모델

할일과 일정을 하나의 **항목(item)** 으로 통합한다.

| 필드 | 설명 |
|---|---|
| 제목 | 필수 |
| 중요 여부 | 토글 (기본 아니오) |
| 마감일 | 선택. 긴급도 계산에 사용 |
| 시작·종료 시각 | 선택. 값이 있으면 일정으로도 표시 |
| 완료 여부 | 기본 미완료 |
| 소유자 | 사용자 ID |

- 시각이 없으면 할일, 있으면 일정. 같은 항목이 모든 뷰에 나타난다.
- 시작 시각이 있고 마감일이 없으면, 시작 날짜를 마감일로 간주한다.
- 긴급도는 저장하지 않고 마감일에서 계산한다.

## 4. 동작 규칙

- **긴급**: 미완료이고 마감일이 오늘 이전(마감 지남), 오늘, 또는 내일. 그 외와 마감일 없음은 긴급하지 않음.
- **사분면**: 중요×긴급 → ① 중요·긴급, ② 중요·덜 긴급, ③ 덜 중요·긴급, ④ 나머지.
- **오늘 할 일**: 미완료이고 마감일이 오늘이거나 그 이전(마감 지남)인 항목. 정렬은 마감 지남 → ① → ② → ③ → ④ 순, 같은 그룹 안에서는 마감일이 빠른 순.
- **마감일 없는 항목**: 오늘 화면에는 나오지 않고 매트릭스 화면에만 나온다. (가정 — 검토 시 확인)
- 날짜·시각 기준은 사용자 기기의 로컬 시간대.
- 검증: 제목 필수, 종료 시각은 시작 시각 이후.

## 5. 화면

- 하단 탭 3개(오늘 / 캘린더 / 매트릭스) + "+" 버튼.
- **오늘**: 위에 오늘 일정 타임라인, 아래에 오늘 할 일(위 정렬 규칙). 마감 지난 항목은 맨 위 강조. 체크 박스로 즉시 완료.
- **캘린더**: 주간/월간 토글. 일정은 시간 블록, 할일은 마감일 칸에 작은 표시. 중요 항목은 구분 표시. 날짜를 누르면 그날 목록. 빈 날짜·시간대를 누르면 입력 창에 날짜·시각이 미리 채워짐.
- **매트릭스**: 미완료 항목 전체를 2×2로 표시. 보기 전용.
- **항목 입력·수정 창**: 제목만 적어도 저장. 나머지는 선택. 항목을 눌러 수정.
- 드래그로 옮기기·시간 늘리기는 하지 않는다.

## 6. 오류 처리

- 저장·불러오기 실패 시 화면에 오류 메시지를 보여주고 다시 시도할 수 있게 한다.
- 오프라인 지원 없음. 네트워크가 끊기면 읽기·쓰기가 실패하며 위 메시지로 알린다.
- 인증이 만료되면 로그인 화면으로 이동한다.

## 7. 테스트

- 단위 테스트: 긴급도 계산, 사분면 분류, 오늘 할 일 정렬, 입력 검증(경계: 오늘·내일·어제·마감일 없음·시각만 있는 항목).
- 접근 제어 테스트: 사용자 A가 사용자 B의 항목을 읽거나 수정할 수 없다.
- 화면: 주요 흐름(항목 추가 → 오늘·캘린더·매트릭스 반영 → 완료)을 수동 또는 E2E로 확인.

## 8. 범위 밖

반복 일정, 알림·푸시, 태그·프로젝트, 공유·협업, 외부 캘린더 연동, 드래그 조작, 오프라인 지원.
